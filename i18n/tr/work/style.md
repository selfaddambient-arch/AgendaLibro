# トルコ語版の文体と訳語の決め（tr）

## 敬称と文体
- 読者への呼びかけは丁寧形の **siz**（動詞は -siniz／-ınız 系、命令は -in／-ın 系）。「sen」は使わない。会話の引用の中で、著者が部下や身内に言う箇所だけ口語（例：「Bak!」「Kusura bakma」）を許す
- 語りは一人称（ben）の過去形・現在形の混在を英語版に合わせる。文体は話し言葉に近い、誠実で平明な書き言葉
- 人物の代名詞：トルコ語の o は性別を示さない。著者・店主・藤井氏とも「o」または名前・役割で書く。性別を示す語（Bay／Bayan）は原文にある呼称（Bay A・Bay B・Bay Bonta）だけ英語版どおり使い、それ以外では使わない
- 数字：dot（¥8.500、$9,3、%40）。パーセントは前置き（%88,1）。時刻は 24 時間（18.00・22.30）
- 日付：日本語版の「12/24」は 24/12（日/月）に直した

## 語の決め
- 副店長＝müdür yardımcısı（「yardımcı müdür」は不採用）
- 店・お店＝dükkân（小さな店）／mekân（場所）／bar／restoran。「mağaza」は物販の語なので使わない
- AI＝yapay zekâ（長音符 â を付ける。「yapay zeka」は不採用）
- バイブコーディング＝vibe coding（そのまま）
- 手帳＝defter。AgendaHub 辞書：Mesai Defteri／Kârlılık Defteri／İkinci Mekân Defteri／Destek Rehberi／Işık Defteri／Sohbet Defteri。辞書に無い窓の案：Maliyet Defteri（原価）／Müdavim Defteri（常連）／Vardiya Defteri（当番）
- 黒革の手帳＝Siyah Deri Defter
- 図＝Şekil、コラム＝Not Kutusu、はじめに＝Giriş、おわりに＝Son Söz、第N章＝Bölüm N
- 屯＝Tamuro、T-AI-MURO・Agenda 製品名はそのまま

## 大文字小文字・母音調和の注意
- トルコ語の i／İ と ı／I は別の文字。大文字化は İ（点あり）と I（点なし）を区別する。表紙の帯文字は手で大文字（KİŞİLİK、YAPAY ZEKÂ）にし、CSS の text-transform は使わない
- 固有名詞の語尾は apostrophe を付けて、最後の音の母音調和に合わせる（Tamuro'nun、Tamuro'ya、Quatre Épices'in、AgendaTurno'ya）。外来の名の最後の母音で選ぶ（Gemini'nin、Firebase'i、Colab'in、X'te）
- 外国語名の発音で語尾を決める（Excel'e、Python、Node.js'i）
