1. 【種別】① 意味の取り違え
【該当箇所の引用】`un lien vers le Guide de la Prochaine Étape`
【問題点】飲食後の「2軒目の案内」（別の店へのはしご酒・二次会）を「次のステップへの案内」と取り違え、架空のガイド名に誤訳している。
【修正案】`un lien vers des recommandations pour le second verre`（または `un lien vers nos suggestions pour la seconde partie de soirée`）

2. 【種別】① 意味の取り違え
【該当箇所の引用】`comme « le rendre illisible de l'extérieur »`
【問題点】顧客データが外部から不正に取得・閲覧されないようにする安全対策を、文章やコードを（視覚的に）判読不能にするという意味の「rendre illisible」と取り違えている。
【修正案】`comme « empêcher tout accès aux données depuis l'extérieur »`（または `comme « rendre les données inaccessibles depuis l'extérieur »`）

3. 【種別】① 意味の取り違え
【該当箇所の引用】`le formulaire chargeait 35 jours de données de réservation directement depuis l'écran. Si l'écran peut les lire, alors quiconque sait comment de tels écrans sont construits peut lire les mêmes données.`
【問題点】「画面から直接読み込む」（ブラウザ・フロントエンド側でAPI等を叩いてデータを直接保持していた）脆弱性を、物理的な画面表示から読み取っているかのように直訳してしまっている。
【修正案】`le formulaire chargeait 35 jours de données de réservation directement côté client. Si ces données sont accessibles côté client, quiconque comprend le fonctionnement d'une page web peut lire ces mêmes données.`

4. 【種別】① 意味の取り違え
【該当箇所の引用】`« le casser, et confirmer qu'il échoue »`
【問題点】「le」が直前の「tests」を受けて「テスト自体を壊す」意味に読めるが、実際にわざと壊すのはテストではなくプログラム（コード）である。
【修正案】`« casser délibérément le code pour vérifier que le test échoue »`

5. 【種別】① 意味の取り違え
【該当箇所の引用】`le jugement de réservation`
【問題点】予約条件を満たしているかどうかの判定・処理ロジックに対し、司法判断や道徳的判断を意味する「jugement」を用いており不自然。
【修正案】`la validation des réservations`（または `l'admissibilité des réservations`）

6. 【種別】③ その言語の読者に伝わらない箇所
【該当箇所の引用】`l'administration de l'établissement` / `est surveillée par la direction` / `puis la direction tranche` / `La direction ne regarde qu'en cas d'arrêt` / `le mot de la direction`
【問題点】ワンオペの個人バー店主の語りであるにもかかわらず、「店主」「管理者」を一貫して大企業の取締役会や行政組織を想起させる「la direction」「l'administration」と訳しており、実態と規模感が読者に誤解される。
【修正案】文脈に応じて `le patron`、`le gérant`、または筆者の一人称（`moi-même` / `mon arbitrage`）に改める（例：`le mot du patron`、`puis le gérant tranche`、`l'adresse e-mail de notification du bar`）。

7. 【種別】③ その言語の読者に伝わらない箇所
【該当箇所の引用】`feuilles inférieures`
【問題点】モバイルUI部品である「ボトムシート」を「下の葉・紙」と直訳しており、フランス語圏の開発者や読者には意味が通じない。
【修正案】`Bottom sheet`（フランス語圏のUI用語でも英語のまま使用される）または `panneau inférieur` / `volet inférieur`

8. 【種別】② 不自然な表現
【該当箇所の引用】`des données de vraies personnes`
【問題点】テスト用ダミーデータに対する「本物のお客様のデータ（実顧客データ）」を「生身の人間のデータ」と直訳しており表現が不自然。
【修正案】`des données réelles de clients`（または `des données de clients réels`）

9. 【種別】② 不自然な表現
【該当箇所の引用】`comme cela subsistait dans l'enregistrement` / `les anciens enregistrements d'avant la réécriture`
【問題点】Gitのコミット履歴やGitHub上に残る古い履歴キャッシュを指して「enregistrement（録音やデータベースの1レコード）」を用いておりGit用語として不自然。
【修正案】`comme cela subsistait dans l'historique` / `les anciennes traces d'avant la réécriture conservées par GitHub`

10. 【種別】② 不自然な表現
【該当箇所の引用】`Huit trous dans le formulaire de réservation` / `Et des trous comme ceux-ci se tapissent tranquillement`
【問題点】システムの欠陥・脆弱性を「trou（穴）」と直訳しており、擬人化の「se tapissent tranquillement（静かに身を潜める）」もソフトウェアの文脈としてぎこちない。
【修正案】`Huit failles dans le formulaire de réservation` / `Et de telles failles restent silencieusement tapies à l'intérieur de programmes qui semblent fonctionner.`

11. 【種別】② 不自然な表現
【該当箇所の引用】`j'ai utilisé une machine pour vérifier que c'était réellement fermé.`
【問題点】スクリプトやCIによる自動テストを「物理的な機械装置を使って確かめた」かのように直訳しており不自然。
【修正案】`j'ai mis en place une vérification automatisée pour m'assurer que l'accès était bien verrouillé.`

12. 【種別】② 不自然な表現
【該当箇所の引用】`un en-tête épais et impressionnant` / `un en-tête épais avec de longues explications`
【問題点】Webサイトのヘッダーの高さ・占有面積が大きすぎることを、物体の厚みを表す「épais」で表現するのはWebデザイン用語として不自然。
【修正案】`un en-tête haut et imposant` / `un en-tête volumineux et surchargé d'explications`

13. 【種別】② 不自然な表現
【該当箇所の引用】`le journal d'audit qui enregistre les confirmations de réservation échouait à chaque fois`
【問題点】ログ（記録ファイルそのもの）が失敗していたのではなく、監査ログへの「記録処理・書き込み」が失敗していたため主述の論理が不自然。
【修正案】`l'écriture dans le journal d'audit des confirmations de réservation échouait systématiquement`

14. 【種別】② 不自然な表現
【該当箇所の引用】`L'IA n'avait pas su dessiner d'images`
【問題点】デザインAIが画面カンプやビジュアルモックアップを生成できなかった文脈で、「dessiner d'images（お絵描きをする）」と表現するのは不自然。
【修正案】`L'IA n'avait généré aucun visuel`（または `L'IA n'avait pas produit la moindre maquette graphique`）

15. 【種別】② 不自然な表現
【該当箇所の引用】`séparées des programmes d'écran`
【問題点】フロントエンド（画面側）のコードとビジネスロジックの分離を指す表現として「programmes d'écran」は不自然。
【修正案】`séparées du code de l'interface`（または `séparées du frontend`）

16. 【種別】② 不自然な表現
