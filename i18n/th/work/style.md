# สไตล์การแปลภาษาไทย (ทุกส่วนต้องตรงกัน)
- ผู้อ่านคือเจ้าของร้านเล็ก ภาษาเขียนที่เป็นกันเอง สุภาพ อ่านลื่น ไม่แข็งแบบแปลตรงตัว ตัดประโยคยาวให้สั้น
- ห้ามใช้สรรพนามบอกเพศ/คำลงท้ายบอกเพศ: ผม ฉัน ดิฉัน เรา(ในความหมายผู้เขียนคนเดียวให้เลี่ยง) ครับ ค่ะ คะ เขา เธอ ท่าน(ไม่ใช้)
  - ผู้เขียนพูดถึงตัวเอง: ละประธาน (ภาษาไทยทำได้) หรือใช้ "ผู้เขียน" เท่าที่จำเป็น; ห้ามใช้ ผม/ฉัน/ดิฉัน เด็ดขาด
  - เรียกผู้อ่าน: "คุณ" (ละได้) ; ลูกค้า/พนักงาน/เจ้าของร้าน/ผู้ช่วย ใช้คำนามหรือละประธาน ไม่ใช้ เขา/เธอ
  - ไม่ใช้คำลงท้าย ครับ/ค่ะ/คะ ; ใช้ "นะ" ได้เล็กน้อยเป็นกลาง
- เลขอารบิก (1,000 / 0.5) ไม่ใช้เลขไทย
- ในภาษาไทยไม่เว้นวรรคระหว่างคำ ให้เว้นวรรคเฉพาะตามจังหวะประโยค/ระหว่างอังกฤษกับไทย และเรียงประโยคให้ตัดบรรทัดได้ธรรมชาติ
- ชื่อหนัง/อ้างอิงข้ามเล่ม (เขียนเป็น *ชื่อ*): เล่ม 1 = *รองผู้จัดการ AI* ; เล่ม 2 = *สร้างมาเพื่อบาร์ของเรา*
- ป้ายภาพ: 【ภาพที่ 1-1】คำบรรยาย ; หมายเหตุหน้าจอ *(The screen is in Japanese.)* -> *(หน้าจอเป็นภาษาญี่ปุ่น)*
- ตัวเลขเงิน: ¥8,500 (ประมาณ $57) — รูปแบบเดียวกับภาษาอังกฤษ ตัวเลขตรงกันทุกตัว ช่วง: ¥4,500–¥5,700 (ประมาณ $30–$38) ตามอังกฤษ
- หมายเหตุญี่ปุ่น *(…)* วางตำแหน่งเดียวกับอังกฤษ แปลเป็นไทย
- ปี/วันที่สัมพัทธ์ (ปีที่แล้ว ปีนี้) ให้ระบุปีกำกับถ้าจำเป็น (ต้นฉบับบันทึกเมื่อ ต.ค. 2026 / เล่ม 1 ม.ค. 2026)
