1. 【残存日本語】
   - **引用**: `외부 도구(커넥터, MCPサーバー)를 추가する画面を開き、이 URL을 등록해 주세요.`
   - **問題点**: 「サーバー」および「する画面を開き、」が翻訳されず、日本語のまま残っています。
   - **修正案**: `외부 도구(커넥터, MCP 서버)를 추가하는 화면을 열어 이 URL을 등록해 주세요.`

2. 【① 意味の取り違え】
   - **引用**: `“타무로 오늘 밤 열려 있어?”`
   - **問題点**: 空席の有無を尋ねる「屯は今夜空いてる？」が、営業中かどうかを尋ねる「열려 있어?（開いてる？）」と取り違えられています。
   - **修正案**: `“타무로 오늘 밤 자리 있어?”`（または `“타무로 오늘 밤 자리 비어 있어?”`）

3. 【① 意味の取り違え】
   - **引用**: `혼자 오셔도 눈에 띄지 않습니다.`
   - **問題点**: 周囲から孤立せず気まずくならないという意味の「ひとりでも、浮きません」が、「目立たない／人目につかない（눈에 띄지 않다）」と取り違えられています。
   - **修正案**: `혼자 오셔도 어색하지 않습니다.`（または `혼자 오셔도 겉돌지 않습니다.`）

4. 【② 不自然な表現】
   - **引用**: `자기 AI`（`물론 자기 AI에서도`, `자기 AI(Claude나 ChatGPT 등)`, `자기 AI에게`）
   - **問題点**: 読者向けの「あなたのAI／お使いのAI」の訳語として三人称再帰代名詞・親称の「자기」を機械的に充てており、極めて不自然です。
   - **修正案**: `사용하시는 AI` または `여러분의 AI`（例: `물론 사용하시는 AI에서도`, `사용 중인 AI의 설정에서`, `AI에게`）

5. 【② 不自然な表現】
   - **引用**: `마음대로 고른 MCP 서버`
   - **問題点**: 原文の「自分で選んだ（任意の／ユーザー自身が指定した）」が「勝手気ままに選んだ（마음대로 고른）」という投げやりで不自然なニュアンスになっています。
   - **修正案**: `직접 선택한 MCP 서버`（または `임의로 선택한 MCP 서버`）

6. 【② 不自然な表現】
   - **引用**: `설명한 장치 가운데에는`
   - **問題点**: 「この本に書いた仕組み」の「仕組み」に「장치（装置・仕掛け）」を充てており文脈上硬く不自然で、「この本に書いた」という修飾も単なる「説明した」に端折られています。
   - **修正案**: `이 책에서 소개한 방식 중에는`（または `이 책에 담긴 시스템 중에는`）

7. 【③ その言語の読者に伝わらない箇所】
   - **引用**: `사람이 모이는 곳에서 기다리고 있겠습니다.`
   - **問題点**: 店名「屯（たむろ＝人が集まる場所）」に掛けた原文の言葉遊びのニュアンスが、韓国語読者には伝わりません（文意自体は通じます）。
   - **修正案**: ニュアンスを補う場合: `‘타무로(屯)’라는 이름처럼 사람이 모이는 공간에서 기다리고 있겠습니다.`

8. 【事実・表記の変更】
   - **引用**: `Raku Bonta`
   - **問題点**: 原文の著者名「本多楽」が、一般的な韓国語（ハングル）表記ではなく英字の名・姓順に変更されています。
   - **修正案**: `본타 라쿠`（または漢字併記で `본타 라쿠(本多楽)`）
