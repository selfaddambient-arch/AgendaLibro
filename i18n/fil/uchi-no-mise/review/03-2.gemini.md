1. 
   - **区分**：① 意味の取り違え
   - **該当箇所**："Sa ngayon, maraming SaaS ang pinagtatakbuhan ng mga restawran."
   - **問題点**：英語の「run on / run a business（〜で営業する）」の機械的な直訳により「pinagtatakbuhan」が使われていますが、「〜から逃げ出す対象」や「避難先」という意味になり、原文の「〜を使って営業している」という意味になりません。
   - **修正案**：`Sa ngayon, maraming SaaS ang ginagamit sa pagpapatakbo ng mga restawran.`

2. 
   - **区分**：① 意味の取り違え
   - **該当箇所**："Sinabi ni Jensen Huang, CEO ng Nvidia, na hindi papalitan ng mga AI agent ang software kundi gagamitin nila ito para sa mga tao"
   - **問題点**：原文の「人の代わりに（人間が操作する代わりにAIがソフトウェアを使う）」が「para sa mga tao（人間のために）」と誤訳されており、操作代行の論旨がずれています。
   - **修正案**：`Sinabi ni Jensen Huang, CEO ng Nvidia, na hindi papalitan ng mga AI agent ang software kundi gagamitin nila ito sa halip na mga tao`

3. 
   - **区分**：② 不自然な表現
   - **該当箇所**："Marami ring iba ang nakakakita na lalo pang lalakas ang SaaS na sumisipsip ng AI."
   - **問題点**：「AIを取り込む」を「sumisipsip（吸う・吸い上げる）」と直訳しており極めて不自然な上、タガログ語の俗語「sipsip（ごますり・媚び諂い）」を想起させます。
   - **修正案**：`Marami ring iba ang nakakakita na lalo pang lalakas ang SaaS na nag-iintegrate ng AI.`（または `...SaaS na nagsasama ng AI.`）

4. 
   - **区分**：② 不自然な表現
   - **該当箇所**："Maaaring parang kuwento tungkol sa mga investor at sa industriya ng IT ang debateng ito. Pero para sa mga restawran, mas pamilyar na anyo ang kinukuha ng parehong bagay."
   - **問題点**：英語表現「takes a more familiar form」の逐語訳（kinukuha ng parehong bagay）になっており、フィリピン語として不自然です。
   - **修正案**：`Maaaring parang kuwento tungkol sa mga investor at sa industriya ng IT ang debateng ito. Pero para sa mga restawran, mararanasan ang parehong bagay sa mas pamilyar na paraan.`

5. 
   - **区分**：② 不自然な表現
   - **該当箇所**："Maging tapat tayo. Sa panahong isinusulat ko ang librong ito..."
   - **問題点**：「Maging tapat tayo」は包括形代名詞「tayo」により「（読者と私で）お互いに正直になりましょう」という呼びかけになり、著者が自身の現状を率直に告白する文脈に合いません（次項の「Magiging tapat pa ako」とも不整合です）。
   - **修正案**：`Magiging tapat ako. Sa panahong isinusulat ko ang librong ito...`

6. 
   - **区分**：② 不自然な表現
   - **該当箇所**："Nasa lugar na ang sistema para sa pagbuo, pero ang sistema para makilala ay nasa unahan pa."
   - **問題点**：「仕組みが整った」を英語の "in place" から「Nasa lugar na（所定の場所にある）」と直訳しており不自然です。また「これから」に対する「nasa unahan pa（前方にある）」も不自然な空間表現になっています。
   - **修正案**：`Handa na ang sistema para sa pagbuo, pero ang sistema para makilala ay kailangan pang itatag (o nasa hinaharap pa).`

7. 
   - **区分**：② 不自然な表現
   - **該当箇所**："Ang librong ito ay nilalayon ding maging tomo para sa layuning iyon, ang makilala."
   - **問題点**：「一冊」を「tomo（大著・分冊・巻）」と直訳しており、文脈に対して大仰で不自然です。
   - **修正案**：`Ang librong ito ay isa ring paraan para sa layuning iyon, ang makilala.`

8. 
   - **区分**：① 意味の取り違え
   - **該当箇所**："Bumilis ang pagbuo dahil sa AI. Pero ibang trabaho ang pagpapatuloy ng paggamit."
   - **問題点**：「使い続けてもらう（顧客に継続利用してもらうこと）」という他動的な顧客維持の業務が、単に「利用を継続すること（pagpapatuloy ng paggamit）」と訳され、主客関係が抜け落ちています。
   - **修正案**：`Bumilis ang pagbuo dahil sa AI. Pero ibang trabaho ang kailangan para patuloy itong gamitin ng mga customer.`

9. 
   - **区分**：① 意味の取り違え
   - **該当箇所**："Pagpapaliwanag ng dahilan kapag tumataas ang presyo."
   - **問題点**：「値段を上げるとき（店主が主体的に値上げを行うとき）」という能動的行為が、「kapag tumataas ang presyo（価格が勝手に上がるとき）」と自動詞的な自然発生として訳されています。
   - **修正案**：`Pagpapaliwanag ng dahilan kapag magtataas ng presyo.`

10. 
    - **区分**：② 不自然な表現
    - **該当箇所**："At higit sa lahat, ang pagpapanatili nitong tumatakbo nang hindi hinahawakan ng may-ari." および "Ang tool na hindi gumagana kung hindi hinahawakan ng may-ari araw-araw ay sa huli ay makakansela."
    - **問題点**：ソフトウェアを「手動操作する・手を加える」という意味の「触る」が、「hinahawakan（手で物理的に触れる・握る）」と直訳されており不自然です（後者には「ay sa huli ay」という助詞の重複もあります）。
    - **修正案**：前者：`...nang hindi kailangang galawin ng may-ari.`（または `pakialaman`）／ 後者：`Ang tool na kailangan pang asikasuhin ng may-ari araw-araw para gumana ay kalaunan ding ipakakansela.`

11. 
    - **区分**：③ その言語の読者に伝わらない箇所
    - **該当箇所**："Una, magdagdag ng isang libreng notebook."
    - **問題点**：著者が自作ツールを「手帳」と呼ぶ比喩を「libreng notebook」と直訳しているため、読者には紙のノートやPCのメモ帳アプリ等を追加するように誤認され、ツールの導入であることが伝わりません。
    - **修正案**：`Una, magdagdag ng isang libreng tool.`（または `Una, mag-install ng isang libreng app (tulad ng Talaan ng Ilaw).`）

12. 
    - **区分**：① 意味の取り違え
    - **該当箇所**："Sa kabilang banda, walang hangganang upuan ang benta ng mga tool."
    - **問題点**：「walang hangganang upuan（無限の椅子・際限のない椅子）」という不自然な文法破綻の句になっており、「座席数による売上の上限がない」という意味が崩れています。
    - **修正案**：`Sa kabilang banda, walang limitasyon sa bilang ng mga upuan ang benta ng mga tool.`

    - **区分**：① 意味の取り違え
    - **該当箇所**："Para sa paghahatid, server lang ang kailangan, at walang stock o bodega sa bawat bansa."
    - **問題点**：原文の「要りません（不要である）」が「walang stock o bodega（在庫や倉庫が存在しない）」と欠如の事実にすり替わっており、物理的拠点を持つ必要がないというビジネスモデル上の利点が伝わりません。また「配信」が物理配送を連想させる「paghahatid」になっています。
    - **修正案**：`Para sa pamamahagi (distribution), server lang ang kailangan, at hindi kailangan ang stock o bodega sa bawat bansa.`
